# UI/UX Design Skill

When designing or improving the frontend:

- First inspect the existing UI and understand the current design system.
- Create a modern, professional SaaS interface.
- Prioritize clear visual hierarchy and simple navigation.
- Use consistent spacing, typography, colors, borders, shadows, and component styles.
- Keep the interface clean and avoid unnecessary decoration.
- Make layouts responsive for desktop, tablet, and mobile.
- Ensure buttons, forms, cards, tables, alerts, and navigation are visually consistent.
- Use Luicide Icons CDN instead of normal Emojis.
- Use clear loading, success, error, and empty states.
- Follow accessibility best practices.
- Do not introduce unnecessary dependencies.
- Reuse existing components when possible.
- Do not rewrite working application logic just to change the UI.
- Before making large design changes, inspect the relevant frontend files.
- After changes, verify that the UI works correctly and remains responsive.
